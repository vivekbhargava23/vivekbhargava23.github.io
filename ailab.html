A1 · flagship

AI-Augmented Investment Analytics Platform

Solo-built · Python / Streamlit · ongoing personal project
Active build
Clean architecturePydantic v2German tax engineAgentic AI
  • A personal investment-analytics platform on a four-layer clean architecture — UI, services, domain, ports & adapters — with a zero-I/O domain layer enforced by import-boundary linting in CI and strictly typed boundaries via Pydantic v2.
  • Domain layer includes a German FIFO capital-gains tax engine implementing the flat-rate investment-income tax, the annual saver's tax-free allowance, and loss-offset carry-forward buckets — unit-tested against hand-calculated references — plus a pre-trade simulator computing exact lot consumption and tax impact before a trade.
  • Multi-source data layer composes market-data APIs, FX feeds, and broker CSV imports through adapter/composite patterns, with TTL caching and ISIN-to-ticker resolution; FX-aware EUR-native valuation with correlation, concentration, and performance analytics.
  • Shipped as 70+ tickets across 7 milestones with an 867-test regression suite; CI runs tests, type-checking, and architecture-boundary linting on every PR.
  • Built and hardened a human-in-the-loop agentic-AI delivery workflow: a chat surface drafts schema-compliant tickets; a CLI implementation agent executes one ticket per branch/PR with deterministic state transitions tied to GitHub Issues; branch protection forces PR-only merges.
